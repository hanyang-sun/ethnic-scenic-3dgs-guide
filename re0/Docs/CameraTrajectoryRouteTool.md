# 相机轨迹半自动路网工具

工具入口：Unity 菜单 `Tools → 导览 → 相机轨迹生成路网`。实现文件为 `Assets/Editor/CameraTrajectoryRouteWindow.cs`；它只在 Unity 编辑器中运行，不会进入玩家构建。

## 使用步骤

1. 打开要制作导览的场景。先在 `TourApp` 中指定 3DGS Renderer 和地面 Collider，并给需要避开的实体设置 `TourObstacle` 层碰撞体。
2. 打开工具窗口，确认“目标 TourApp”，选择该 3DGS 数据集的 `cameras.json`。文件可以放在 Unity `Assets` 目录之外。
3. 指定起止帧。当前 White Art Gallery 可先用 `1～90` 预览第一段环绕轨迹；换数据集时需要根据其拍摄顺序重新选择。
4. 点击“生成预览”，在 Scene 视图检查橙色节点与线段。窗口会列出落地失败、障碍内相机位和断开路段的数量。若路线缺段，调整地面或碰撞体、帧范围、最大跳距和最大边长后重新预览。
5. 确认无明显穿墙或跨越不可走区域后，点击“确认并写入 TourApp”。已有 `Nodes/Edges` 会被替换；默认按旧节点位置将 POI 映射到最近的新节点，超过距离限制则拒绝写入。也可以明确选择清空 POI。写入支持 Unity 撤销。
6. 在 `TourApp` Inspector 和 Scene 视图继续人工调整节点、边、出生点、POI 和到达区域，再保存场景并运行测试。

## 生成规则与边界

- 按 `img_name` 末尾数字排序，不依赖 JSON 中的记录顺序；只使用相机 `position`，不会解析展品语义。
- 相机坐标经过当前 3DGS 对象的 Transform 转成 Unity 世界坐标，再向下射线投影到 `TourApp.ground`。因此**必须先把模型方向和物理地面校准**。
- 相邻相机位超过帧号间隔、距离或地面高差限制，或者 Layer 9 障碍阻断时，工具会断开路径，不猜测连接。路径偏差与最长边参数用来保留转弯并减少密集节点。
- “首尾接成闭环”只在整段轨迹连续、端点够近且没有障碍时生效。默认关闭，避免误连不同拍摄圈。
- 输出的是待审核的**候选路网**，不是从 3DGS 自动识别出的真实步行区；它不会创建地面、墙体碰撞、POI 或 VR 控制。

当前运行时 `TourApp` 仍采用水平移动。若地面明显倾斜或有台阶，单靠这个工具生成不同高度的节点还不够，需先实现贴地移动或分层通行逻辑。
