# re0

民族建筑景区 3DGS 导览项目的从零复建工程。这里从一个新的 Unity 工程开始，逐步完成 Garden 技术原型，再加入地图、帮助、暂停、重置、访问计数、浏览日志和障碍感知的路线重规划。

## 当前状态

仓库起点已建立；Unity 工程、3DGS 模型和运行脚本尚未加入。下一步由成员 A 使用 **Unity 6000.3.24f1** 建立 **Universal 3D** 工程，再将 Unity 生成的 `Assets`、`Packages` 和 `ProjectSettings` 纳入本目录，并与组员确认 URP 和 3DGS 插件版本。

## 分工

- **A｜场景与运行**：3DGS、主场景、坐标、碰撞、移动、Windows 构建。
- **B｜景点与交互**：景点数据、界面、地图、路线显示、访问计数、JSONL 日志。
- **C｜路线与研究**：手工路网、最短路、障碍检查、重规划、到达判定。

每人可以借助 AI 编写和排查代码，但须能说明自己模块的挂载位置、输入输出、关键逻辑和验证结果。主场景由 A 集成，B/C 分别提交数据、界面及导航模块。

## 资源约定

原始 Garden PLY、相机文件和导入生成的二进制资源目前不在仓库中。加入大型资源前，先确认来源和共享方式，并约定 Git LFS 或共享存储；Unity 资源及其 `.meta` 文件应成对提交。

工作计划见项目计划书及三人任务表。当前 `re0` 不包含参照工程代码或场景。
